TotalSegmentator Wrapper for Mac bundled Sample 1 notices

Sample purpose
- This bundled sample is for non-clinical UI preview and local workflow testing.
- It is not for diagnosis, treatment planning, quantitative accuracy evaluation,
  or any other clinical use.
- The bundled sample is not DICOM. It is a derived NIfTI preview input plus
  precomputed, non-clinical segmentation preview artifacts.

Source data
- Source dataset: 3D Slicer SampleData "CBCT-MR Head" / "CBCTMRHead".
- Source file: DZ-CBCT.nrrd.
- Source SHA256:
  4ce7aa75278b5a7b757ed0c8d7a6b3caccfc3e2973b020532456dbc8f3def7db
- 3D Slicer SampleData source:
  https://github.com/Slicer/Slicer/blob/main/Modules/Scripted/SampleData/SampleData.py
- The 3D Slicer SampleData source states that MRHead, CBCT-MR Head, and
  CT-MR Brain datasets were donated to the 3D Slicer project for unrestricted
  use.

TotalSegmentator Wrapper for Mac handling
- TotalSegmentator Wrapper for Mac is an unofficial Mac wrapper powered by
  TotalSegmentator. It is not the official TotalSegmentator application or project.
- TotalSegmentator Wrapper for Mac does not send DICOM, CT, processing results, or
  generated 3D files during setup or 3D preview creation.
- The bundled sample is included only to make the first-run experience usable
  before the user chooses their own local data.
